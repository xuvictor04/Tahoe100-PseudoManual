# Corrections and retractions

> [!summary] In one line
> The ledger of claims in this vault's written layer that were found wrong, weakened or withdrawn — recorded, not
> quietly fixed.

## How to use it

When a written note (a concept note or a gene fragment in `tahoemap/vault_seed/`) turns out to be wrong:

1. Correct the note itself, and add a dated line here: what was claimed, what is true, the evidence (a table path,
   a run, a paper), and the note it was in.
2. Do not delete the old claim silently. If it matters for reading older material, say so in the corrected note
   too ("*corrected: an earlier version said …*").
3. Generated numbers are not corrected here: they are rebuilt from the data on every run. If a generated number
   is wrong, the fix belongs in the code, and the ledger records what changed and from which version.
